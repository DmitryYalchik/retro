# Ретро

Редактор ретро с экспортом в Markdown: блоки «Плюсы», «Минусы», «Вопросы», «Идеи», «Планы», «Преза», «Запись», стикеры записей (S, M, L, UX, ЗП, ШТУРМ), жирный, курсив и зачёркивание, перенос идеи в планы одной кнопкой и кнопка «Скопировать Markdown» для Mattermost.

**Открыть:** <https://dmitryyalchik.github.io/retro/>

Всё хранится в браузере (localStorage), на сервер ничего не уходит.

## Публикация

Сайт собирается GitHub Actions (`.github/workflows/deploy.yml`) и выкладывается на GitHub Pages **при каждом пуше в `main`**. Через минуту обновлённая страница доступна по ссылке выше.

Внизу страницы видно версию, хеш коммита и дату. Версия берётся из ближайшего тега (`git describe --tags`): на коммите с тегом `v1.1.0` это `v1.1.0`, на следующих — `v1.1.0-2-gabc1234`. Чтобы выпустить ровную версию, поставьте тег и запушьте его вместе с коммитом. Пересобрать без пуша можно вручную: Actions → Deploy to GitHub Pages → Run workflow.
