# Ретро

Редактор конспекта ретро для Mattermost: разделы «Плюсы», «Минусы», «Вопросы», «Идеи», «Планы», «Преза» на отдельных вкладках, теги записей (S, M, L, UX, ЗП, ШТУРМ), жирный, курсив и зачёркивание, перенос идеи в планы одной кнопкой и кнопка «Скопировать в Mattermost».

**Открыть:** <https://dmitryyalchik.github.io/retro/>

Внизу листа — строка быстрой записи (`/`): пишете `+ быстро закрыли баги #s`, Enter — запись ушла в «Плюсы». Префиксы разделов (`+ - ? ! *`) настраиваются в шаблоне, `#тег` ставит тег, `**…**` и `~~…~~` — жирный и зачёркнутый. Удалённую запись можно вернуть кнопкой «Вернуть» или Ctrl+Z.

Теги ставятся кнопкой `+` слева от строки или по Alt+T, в открытом списке — цифрами 1–9. В Mattermost они уходят текстом перед записью: `\[ ШТУРМ | UX | L \]`. Вкладки переключаются по Alt+← / Alt+→ или Alt+1…9. Все сочетания — в меню `⋯` → «Горячие клавиши» или по `?`.

У каждой строки есть таймер обсуждения (⏱): выбираете минуты, запускаете, рядом со строкой идёт отсчёт. Когда время выходит, звучит короткий сигнал, а записи сам ставится тег ШТУРМ. Таймер один на всё ретро.

Разделы, их эмодзи и цвета, теги настраиваются в меню `⋯` → «Шаблон». «Новое ретро» очищает записи и оставляет шаблон.

Кнопка с солнцем в шапке переключает тему: как в системе → светлая → тёмная.

Страница работает без интернета: после первого открытия она и шрифты сохраняются в браузере. В Chrome и Edge её можно поставить как приложение (значок установки в адресной строке). Новая версия сайта подхватывается при следующем открытии с сетью.

Всё хранится в браузере (localStorage), на сервер ничего не уходит. Данные из прошлой версии страницы подхватываются сами.

## Публикация

Сайт собирается GitHub Actions (`.github/workflows/deploy.yml`) и выкладывается на GitHub Pages **при каждом пуше в `main`**. Через минуту обновлённая страница доступна по ссылке выше.

Внизу страницы видно версию, хеш коммита и дату. Версия берётся из ближайшего тега (`git describe --tags`): на коммите с тегом `v1.1.0` это `v1.1.0`, на следующих — `v1.1.0-2-gabc1234`. Чтобы выпустить ровную версию, поставьте тег и запушьте его вместе с коммитом. Пересобрать без пуша можно вручную: Actions → Deploy to GitHub Pages → Run workflow.
